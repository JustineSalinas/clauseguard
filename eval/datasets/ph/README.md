# Philippine annotated set

**Owner:** All three  
**Task:** T7

Hand annotated. Required for Objective 4, because no public dataset covers
Philippine statute.

Day 3 is a full team annotation day and this is the bottleneck of the entire
week. Two annotators per clause minimum, or Cohen's kappa is not computable and
the accuracy numbers are weakly defensible.

If the day overruns, shrink this set rather than extending the day. Small and
kappa-reportable beats large and unmeasured.

Sourcing: real contracts need documented consent, or must be redacted or
synthetic. The panel will ask. Write the answer down before annotation starts,
not after.
