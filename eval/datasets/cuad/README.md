# CUAD subset

**Owner:** Navarro  
**Task:** T7

Contract Understanding Atticus Dataset. Expert annotated, clause level, and
already cited as reference [5] in the proposal's literature review.

Used for clause segmentation and classification accuracy. Using it lets the
results compare against published baselines instead of only against ourselves,
and it removes most of the hand annotation burden.

CUAD is US commercial contract law. It carries nothing about the Civil Code or
the Labor Code, which is why the Philippine set exists alongside it.
